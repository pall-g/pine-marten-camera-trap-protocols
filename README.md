# Pine marten camera-trap protocol comparison

This repository contains the data and R code supporting a comparison of two
camera-trap survey protocols for European pine martens (*Martes martes*) in
northern Sweden: ground-based inaccessible lure stations and tree-mounted
accessible bait stations.

Precise camera-trap coordinates and identifying metadata are not included in
the public data. Anonymised station identifiers are retained because they are
required to link observations to deployments and reproduce the analyses.

## Repository structure

```text

│   └── observation-tableSCPM.csv
├── dataraw2024/

│   ├── deployments_Collection2_ks.csv
│   ├── deployments_Collection3_ks.csv
│   └── observations.csv
├── scripts/
│   └── pine_marten_analysis_final.R
├── outputs/                         # generated by the script
├── README.md
└── LICENSE.md
```

The deployment files contain station identifiers and deployment start and end
times. The observation files contain media or event identifiers, observation
times and species identifications.

## Software requirements

The analysis was developed using R 4.4.1 and requires these packages:

- tidyverse
- lubridate
- MASS
- survival
- survminer
- survRM2
- broom
- patchwork

The script checks for missing packages and reports which ones must be installed.

## Running the analysis

Keep the directory structure and filenames shown above. In R or RStudio, set
the working directory to the repository root and run:

```r
source("scripts/pine_marten_analysis_final.R")
```

Alternatively, from a terminal with R installed:

```sh
Rscript scripts/pine_marten_analysis_final.R
```

The script creates the `outputs/` and `outputs/figures/` directories when they
do not already exist. Existing files with the same output filenames are
replaced.

## Analysis summary

The script:

1. reads and validates the deployment and observation files;
2. restricts sampling to the shared July-November seasonal window;
3. calculates trap effort from deployment intervals;
4. defines independent pine marten events using a 30-minute separation rule;
5. compares naive occupancy using Fisher's exact test;
6. models event counts using a negative-binomial generalised linear model with
   the natural logarithm of trap nights as an offset;
7. compares time to first detection among detected stations using a Wilcoxon
   rank-sum test; and
8. analyses time to first revisit using Kaplan-Meier curves, a log-rank test,
   a Cox model and restricted mean survival time.

The non-parametric Wilcoxon comparison of station-level detection rates is not
included because the negative-binomial model is the primary analysis of event
rates and accounts for sampling effort directly.

## Reproducibility checkpoints

A successful run checks the following values before producing the final output:

| Protocol | Stations | Stations detected | Stations revisited | Independent events | Trap nights |
|---|---:|---:|---:|---:|---:|
| Ground-based lure | 27 | 17 | 7 | 40 | 2,828 |
| Tree-mounted bait | 23 | 17 | 15 | 197 | 2,023 |

The script stops with an error if these checkpoints are not reproduced.

## Data fields and privacy

The analysis requires anonymised deployment or station identifiers, deployment
start and end times, observation timestamps and species identifications. Exact
latitude and longitude are not used. Original unredacted data should be retained
privately and must not be committed to the public repository or its Git history.
